Claude Code 事故防止チェックリスト
（設定レビュー版）

自律で動く Claude Code を、取り消せない事故から守るための、自分でできる点検の一覧です。実際に GitHub の Issue で報告された事故をもとに作りました。一つずつ「今の自分の設定でこれは防げるか」を確かめてください。防げないなら、その場で直せます。

登録は要りません。この頁がそのまま全文です。

この一覧が守るもの（すべて実際に報告された事故）

  • rm -rf が約50GB・1,500ファイルを永久に消した（Issue #49129）
  • 自動承認のまま ~/.ssh が削除され、SSH の鍵が全部消えた（#49554）
  • ~/.git-credentials の個人アクセストークンが確認なしで消えた（#49539）
  • rm -rf がフォルダごと回復不能に消した（#46058・7GB／3,467ファイル）
  • 本番のデータベースに破壊的な DDL が流れた（#46684）
  • サブエージェントが CLAUDE.md のルールを全部無視した（#40459）

共通点は「一度起きると取り消せない」ことです。だから、起きる前に止める仕組みが要ります。

1. 取り消せない削除

  • rm -rf、git reset --hard、git clean -fd を、実行の手前で一度止めて確認する仕組みがあるか
  • ~/.ssh、~/.git-credentials、.env、~/.aws などの重要ファイルへの削除・上書きを、特別に扱って止められるか
  • 「自動承認（auto-approve）」の設定が、破壊的な操作まで素通しにしていないか
  • クラウド同期（Dropbox・OneDrive・iCloud）の下で作業していないか。同期フォルダの削除はゴミ箱を迂回して本当に消えることがある
自分でできる最小の守り：削除は「複製 → 検証 → 削除」の順にします。&& で前の成功に依存させ、沈黙の失敗が次の破壊に繋がらないようにします。

2. main への未検証の push と force-push

  • main / master への直接の push を止める仕組みがあるか
  • git push --force が共有のブランチの履歴を書き換えるのを止められるか
  • 未検証のコードが確認なしに main へ入る経路を塞いでいるか

3. シークレットの漏洩

  • git add . が、API キーや .env を巻き込んで公開のリポジトリに commit するのを防げるか
  • commit の手前で、鍵らしい文字列（トークン・秘密鍵）を検知して止められるか

4. 文脈の喪失と CLAUDE.md の無視

  • コンテキストの窓が枯れそうな時に、警告が出るか（黙って全部忘れる前に気づけるか）
  • 自動の圧縮（compact）の後に、CLAUDE.md のルールが静かに無視されていないか
  • サブエージェントが CLAUDE.md のルールを引き継いでいるか（#40459 の事故）

5. 費用の暴走

  • サブエージェントの多重の起動で、費用が跳ねていないか。使用量の内訳（skills・subagents・plugins・MCP）を見る習慣があるか
  • 使っていない MCP サーバーが、ツールの定義を毎回コンテキストに載せて費用を押し上げていないか
  • 編集後の構文エラーが多数のファイルに連鎖する前に、1ファイルずつ検証しているか

この点検を自動にする

上のチェックは、手でやると必ず抜けます。人間もAIも、疲れると確認を飛ばすからです。無料の道具 cc-safe-setup は、この一覧の主要な項目を「実行の手前で止める」フックとして入れます。

npx cc-safe-setup

破壊的コマンドの遮断、main への push の保護、編集後の構文の検証、シークレットの漏洩の防止、コンテキストの監視などの安全フックが入ります。npm の依存はゼロです（フックの実行には jq が要ります。apt install jq か brew install jq で入ります）。

なお、既定のフックが覆うのは、削除・push・シークレット・構文・コンテキストの主要な事故です。サブエージェントが CLAUDE.md を無視する事故（#40459）や費用の暴走の監視など、一部は追加のフックや CLAUDE.md 側の設定が要ります。

もっと深く、体系的に

一つ一つの事故を「なぜ起きたか」から理解し、多層の防御まで体系的に押さえたい人には、事故防止の本があります。買った後の毎月の更新も、追加の費用なく読めます。この無料のチェックリストは、その本の中核を蒸留したものです。
